# Spendster

A simple full-stack expense tracker built with Next.js, TypeScript, MongoDB, and Mongoose.

## Features

* Add expenses
* Edit expenses
* Delete expenses
* View all expenses
* Calculate total expenses

## Tech Stack

* Next.js
* TypeScript
* React
* MongoDB Atlas
* Mongoose
* Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Shivambhandary75/spendster.git
cd spendster
npm install
```

Create a `.env.local` file:

```env
MONGODB_URI=your_mongodb_connection_string
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
